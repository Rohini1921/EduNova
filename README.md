
# EduNova - Smart Learning Platform

## Project Description

EduNova is an online smart learning platform designed to help students learn programming and other educational subjects.

Students can register, log in and access their personal learning dashboard.

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Firestore
- GitHub

## Features

1. Student Registration
2. Student Login
3. Firebase Authentication
4. Student Dashboard
5. Online Learning Courses
6. Learning Progress Display
7. Logout Functionality

## Project Files

- index.html - Main website page
- style.css - Website design and styling
- script.js - Website functionality
- firebase.js - Firebase connection
- login.html - Login and registration page
- dashboard.html - Student dashboard
- README.md - Project description

## Firebase Setup

1. Create a Firebase project.
2. Register a Web App.
3. Copy the Firebase configuration.
4. Add the configuration to firebase.js.
5. Enable Email/Password authentication.
6. Set up Firestore if database features are needed.

## How to Run

1. Download or clone this repository.
2. Configure Firebase.
3. Run the project using a local development server.
4. Open index.html.
5. Register or log in to access the dashboard.

## Result

EduNova provides a simple student learning platform with registration, login and a personalized dashboard.
